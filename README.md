# 💻 Awesome Developer Tools Online

Free browser-based developer tools. No signup, no install.

## Data Format
- [JSON Formatter](https://run-dev.com/tools/json-formatter/) - Format and validate JSON
- [YAML Editor](https://run-dev.com/tools/yaml-editor/) - Edit YAML online
- [XML Formatter](https://run-dev.com/tools/xml-formatter/) - Pretty-print XML

## Encoding
- [Base64 Encoder](https://run-dev.com/tools/base64-encoder/) - Encode/decode Base64
- [URL Encoder](https://run-dev.com/tools/url-encoder/) - Encode URLs
- [JWT Decoder](https://run-dev.com/tools/jwt-decoder/) - Decode JWT tokens

## Generators
- [UUID Generator](https://gen-kit.com/tools/uuid-generator/) - Generate UUIDs
- [Password Generator](https://gen-kit.com/tools/password-generator/) - Secure passwords
- [QR Code Generator](https://gen-kit.com/tools/qr-code-generator/) - Create QR codes

## Testing
- [API Tester](https://run-dev.com/tools/api-tester/) - Test REST APIs
- [Regex Tester](https://run-dev.com/tools/regex-tester/) - Test regular expressions
